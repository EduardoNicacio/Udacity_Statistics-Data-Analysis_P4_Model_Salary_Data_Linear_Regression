# Rubric

Use this project rubric to understand and assess the project criteria.

## Code Quality

### Criteria

Functionality of code

### Submission Requirements

All code cells can be run without error.

## Statistical Analyses

### Criteria

Data Preparation

### Submission Requirements

Data preparation, including cleaning the dataframe and creating new variables, is performed correctly.

### Criteria

Correct Interpretation of Results

### Submission Requirements

The interpretation of all results from different analyses is correct and includes both statistical reasoning and practical reasoning.

### Criteria

Correct Values for All Statistical Results

### Submission Requirements

All statistical numeric values are calculated correctly. These include model coefficients and metrics associated with model fit.

## Suggestions to Make Your Project Stand Out

- Expanded EDA
- Consider all assumptions of regression and the potential issues with any of them being violated.

## Prepare Your Submission File

You will be graded on **both** the code in the notebook and the results in the presentation deck to ensure you've done everything correctly.

If you worked in the workspace, please download the **completed** Jupyter Notebook containing all your code as a **.ipynb file**. Also, save the **completed** presentation deck containing your results as a **PDF file**. Then, combine both files as a **zip file** for submission.

If you worked on your local machine, save the **completed** presentation deck containing your results as a **PDF file**. And combine it with the **completed** Jupyter Notebook (**.ipynb file**) containing your code as a **zip file**.

### Ready for Submission

Once you have prepared the zip file for submission, you can click on the submit project button at the bottom right. Then you will see a "UPLOAD ZIP FILE" button for uploading the project submission.
